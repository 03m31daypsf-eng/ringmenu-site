RingMenu

마우스 가운데 버튼 또는 Ctrl+Alt+Space로 여는 Windows용 원형 단축 메뉴입니다.

설치파일 다운로드 포터블 ZIP 다운로드

주요 기능

원형 링 메뉴

마우스 가운데 버튼을 누른 상태에서 방향을 선택하고 놓으면 작업이 실행됩니다.

키보드 링 열기

Ctrl+Alt+Space로도 링 메뉴를 열 수 있습니다.

작업 방식 지원

hotkey, run, url, internal 방식으로 원하는 작업을 등록할 수 있습니다.

트레이 설정

윈도우 오른쪽 아래 시계 옆 ^ 안의 작은 RingMenu 아이콘에서 설정과 종료를 할 수 있습니다.

Windows 경고 안내

RingMenu는 개인 개발 중인 무료 베타 앱이라 Windows SmartScreen 경고가 표시될 수 있습니다. 이는 새로 배포된 실행 파일에서 흔히 발생하는 경고이며, 향후 Microsoft Store 배포도 준비 중입니다.
